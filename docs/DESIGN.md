# Дизайн-система: киберпанк-HUD

Владелец выбрал этот стиль 17.11.2026 из четырёх макетов (необрутализм, киберпанк-HUD, Y2K, пастель). До этого были «спокойное стекло» и «Cinema»: оба отвергнуты как корпоративные.

## Цвет
- Фиксированный неон, не из обоев: циан `#00E5FF` (основной), маджента `#FF2BD6` (активное, выбор, тревога), мята `#7AFFD4` (подписи, приветствие), янтарь `#FFD23F`, красный `#FF3355` (ошибки), фон `#05040A`.
- Источник для оболочки — `quickshell/.config/quickshell/theme/Colors.qml`; для терминала, rofi, экрана блокировки, SDDM и рамок Hyprland — шаблоны в `matugen/.config/matugen/templates/` (от matugen берётся только путь к обоям).

## Формы
- Панели — `HudPanel`: скос левого верхнего и правого нижнего угла (`Style.chamfer`), рамка 1 px цвета акцента, у активной — свечение и яркая рамка, уголки-скобки, слабые скан-линии.
- Окна Hyprland — почти прямые углы (3 px), рамка активного окна — вращающийся градиент циан → маджента, свечение циан.
- Терминал — сегменты приглашения со скошенными краями, неоновая палитра.
- rofi, экран блокировки, SDDM — прямые углы, неоновая рамка, надписи вида `>> LAUNCH_`, `>> ACCESS CODE_`, `[ LOGIN ]`.

## Текст
- JetBrains Mono Nerd Font, подписи и заголовки капсом с разрядкой (`Style.hud_letter_spacing`), цифры моноширинные.
- `NeonText`: свечение, расслоение цвета (`split`) для крупных часов, метод `glitch()`.

## Движение
- Короткий «глитч» при появлении и смене состояния (`Style.glitch_duration`), текст уведомлений печатается по буквам (`Style.type_step`), остров перетекает пружиной, шкалы — сегментные.

## Обои
- `scripts/wallpapers/make_wallpapers.py`: неоновая сетка с солнцем, ночной город, плата, неоновый дождь, глитч, пустота с линией горизонта.
